PASO 1 · REQUERIDO

Pídele a tu agente que instale LearnForce

Copia esta instrucción completa en Codex o Claude Code. El agente detectará su carpeta de skills, descargará LearnForce con sus scripts y comprobará que quedó instalada.

Instrucción recomendada para el agente
Instala y configura la skill LearnForce en este equipo. Ejecuta tú todos los comandos necesarios; no me entregues instrucciones para que yo cree carpetas o archivos.

1. Detecta si estás ejecutándote como Codex o Claude Code.
2. Usa la carpeta correspondiente:
   - Codex: $HOME\.codex\skills\learnforce
   - Claude Code: $HOME\.claude\skills\learnforce
3. Descarga el archivo principal desde:
   https://learn.techforce.cl/docs/learnforce-skill/SKILL.md
   y guárdalo como SKILL.md dentro de esa carpeta.
4. Crea la subcarpeta scripts y descarga dentro de ella estos tres archivos:
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/search.ps1
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/lesson.ps1
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/module-lessons.ps1
5. Verifica que existan SKILL.md y los tres scripts.
6. Ejecuta tú mismo estos comandos para dejar preparado el archivo de configuración:
   $config = [IO.Path]::Combine($HOME, '.config', 'learnforce')
   New-Item -ItemType Directory -Force $config | Out-Null
   $envFile = Join-Path $config '.env'
   if (-not (Test-Path $envFile)) { New-Item -ItemType File $envFile | Out-Null }
7. Verifica tú mismo que la carpeta, el .env, SKILL.md y los tres scripts existan.
8. Sólo después de completar todo lo anterior, indícame que cree mi llave en https://learn.techforce.cl/agents.html. No me pidas pegarla en el chat.
9. Déjame únicamente este comando para que yo guarde la llave desde PowerShell sin escribirla en el historial:
   $key = Read-Host "Pega tu API key de LearnForce"; Set-Content -LiteralPath ([IO.Path]::Combine($HOME, '.config', 'learnforce', '.env')) -Value "LEARN_FORCE_API_KEY=$key"; Remove-Variable key
10. Tu respuesta final debe confirmar qué dejaste instalado, mostrar el enlace para crear la llave y el único comando anterior. No me delegues ningún otro comando. Indícame si debo reiniciar el agente.
💡

Después de instalar: reinicia el agente o abre una sesión nueva para que descubra la skill learnforce.

PASO 2 · API KEY

Crea la llave y guárdala en el .env

Después de instalar la skill, crea una llave en el panel de esta página. Guárdala en la ubicación universal de LearnForce; la skill y sus scripts leen exactamente ese mismo archivo.

Guardar la llave desde PowerShell
$key = Read-Host "Pega tu API key de LearnForce"; Set-Content -LiteralPath ([IO.Path]::Combine($HOME, '.config', 'learnforce', '.env')) -Value "LEARN_FORCE_API_KEY=$key"; Remove-Variable key
✓

El comando pide la llave de forma interactiva y la guarda en $HOME/.config/learnforce/.env. Así no queda escrita en el historial del terminal.

BÚSQUEDA BETA

Encuentra qué estudiar según tu intención

Los tres modos comparten la misma entrada y respuesta. La búsqueda cubre las clases, contenidos, transcripciones y recursos de Imperio Agéntico.

Buscar por palabras clave
curl -X POST "$BASE_URL/search/keyword" \
  -H "X-API-Key: $LEARN_FORCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"quiero aprender agentes de WhatsApp","limit":5}'
keywordMás barato

PostgreSQL Full Text Search. No ejecuta modelos.

semanticMás flexible

Busca significado con embeddings OpenAI sobre clases y transcripciones.

hybridMejor ranking

Combina palabras y significado, incluyendo fragmentos y recursos.
