PASO 1 · REQUERIDO

Pídele a tu agente que instale LearnForce

Copia esta instrucción completa en Codex o Claude Code. El agente detectará su carpeta de skills, descargará LearnForce con sus scripts y comprobará que quedó instalada.

✓ Funciona en Claude Code y Codex✕ No funciona en Claude Chat, Claude Cowork ni ChatGPT
Instrucción recomendada para el agente
Instala y configura la skill LearnForce en este equipo. Esta instalación sólo funciona en Claude Code y Codex; no funciona en Claude Chat, Claude Cowork ni ChatGPT. Si no estás en Claude Code o Codex, detente e infórmame. Ejecuta tú todos los comandos necesarios; no me entregues instrucciones para que yo cree carpetas o archivos. No leas el portapapeles sin avisarme, explicar el alcance y recibir mi autorización explícita.

1. Detecta si estás ejecutándote como Codex o Claude Code.
2. Usa la carpeta correspondiente:
   - Codex: $HOME\.codex\skills\learnforce
   - Claude Code: $HOME\.claude\skills\learnforce
3. Descarga el archivo principal desde:
   https://learn.techforce.cl/docs/learnforce-skill/SKILL.md
   y guárdalo como SKILL.md dentro de esa carpeta.
4. Crea la subcarpeta scripts y descarga dentro de ella estos cuatro archivos:
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/search.ps1
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/lesson.ps1
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/module-lessons.ps1
   - https://learn.techforce.cl/docs/learnforce-skill/scripts/key.ps1
5. Verifica que existan SKILL.md y los cuatro scripts.
6. Ejecuta tú mismo estos comandos para dejar preparado el archivo de configuración:
   $config = [IO.Path]::Combine($HOME, '.config', 'learnforce')
   New-Item -ItemType Directory -Force $config | Out-Null
   $envFile = Join-Path $config '.env'
   if (-not (Test-Path $envFile)) { New-Item -ItemType File $envFile | Out-Null }
7. Ejecuta tú mismo:
   Copy-Item (Join-Path $skill 'scripts\key.ps1') (Join-Path $config 'lfkey.ps1') -Force
   $profileFile = $PROFILE.CurrentUserAllHosts
   New-Item -ItemType Directory -Force (Split-Path $profileFile) | Out-Null
   if (-not (Test-Path $profileFile)) { New-Item -ItemType File $profileFile | Out-Null }
   $definition = 'function lfkey { & "$HOME/.config/learnforce/lfkey.ps1" }'
   if (-not (Select-String -LiteralPath $profileFile -SimpleMatch 'function lfkey' -Quiet)) { Add-Content -LiteralPath $profileFile -Value "`n$definition" }
   . $profileFile
8. Verifica tú mismo que la carpeta, el .env, SKILL.md, los cuatro scripts y el comando lfkey existan.
9. Muestra de forma destacada y sin texto previo:
   “ACCIÓN REQUERIDA
   1. Crea tu llave en https://learn.techforce.cl/agents.html
   2. Presiona copiar para dejarla en el portapapeles.
   3. Responde exactamente: LISTO

   Al responder LISTO permites leer una vez el portapapeles exclusivamente para validar esa key y, si funciona, guardarla en $HOME/.config/learnforce/.env. La key permite consultar tus cursos y gestionar tu progreso con tus permisos; permanece hasta eliminarla o revocarla en LearnForce. No se leerá ni guardará otro contenido.”
10. Espera. La respuesta LISTO es la única confirmación necesaria: no vuelvas a pedir autorización.
11. Tras recibirla, ejecuta `& (Join-Path $config 'lfkey.ps1') -ClipboardOnly`. El script valida la key contra la API antes de guardarla. Nunca muestres la llave. Considera éxito únicamente la salida `status: ok` y `api_verified: true`; no hagas una segunda verificación casera del texto del archivo.
12. Si la API confirma la key, informa que LearnForce está lista para usar inmediatamente. No pidas reiniciar: ya leíste SKILL.md en esta sesión.
13. Termina sugiriendo estos prompts:
   - “Usando LearnForce, recomiéndame las 5 mejores clases de Imperio Agéntico para aprender agentes de WhatsApp.”
   - “Usando LearnForce, dime cómo hacer [objetivo] según Imperio Agéntico.”
   - “Usando LearnForce, créame una ruta para aprender [tema] desde cero.”
14. Si no autoriza el portapapeles, ofrece dos alternativas: ejecutar `lfkey` o guardar manualmente una línea `LEARN_FORCE_API_KEY=SU_LLAVE` en `$HOME/.config/learnforce/.env`. No pidas que comparta la llave en el chat.
✓

Sin reiniciar: el mismo agente puede usar LearnForce porque ya leyó su SKILL.md durante la instalación.

Instalación manual

Si prefieres hacerlo tú, copia el comando de tu herramienta en PowerShell.

Codex · PowerShell
$skill="$HOME\.codex\skills\learnforce"; New-Item -ItemType Directory -Force "$skill\scripts" | Out-Null
Invoke-WebRequest "https://learn.techforce.cl/docs/learnforce-skill/SKILL.md" -OutFile "$skill\SKILL.md"
"search","lesson","module-lessons","key" | ForEach-Object { Invoke-WebRequest "https://learn.techforce.cl/docs/learnforce-skill/scripts/$_.ps1" -OutFile "$skill\scripts\$_.ps1" }
Claude Code · PowerShell
$skill="$HOME\.claude\skills\learnforce"; New-Item -ItemType Directory -Force "$skill\scripts" | Out-Null
Invoke-WebRequest "https://learn.techforce.cl/docs/learnforce-skill/SKILL.md" -OutFile "$skill\SKILL.md"
"search","lesson","module-lessons","key" | ForEach-Object { Invoke-WebRequest "https://learn.techforce.cl/docs/learnforce-skill/scripts/$_.ps1" -OutFile "$skill\scripts\$_.ps1" }

Con LearnForce instalada y la llave guardada, no necesitas repetir documentación, endpoints ni credenciales. Reemplaza únicamente el texto entre corchetes.

BÚSQUEDA BETA

Encuentra qué estudiar según tu intención

Los tres modos comparten la misma entrada y respuesta. La búsqueda cubre las clases, contenidos, transcripciones y recursos de Imperio Agéntico.

Buscar por palabras clave
curl -X POST "$BASE_URL/search/keyword" \
  -H "X-API-Key: $LEARN_FORCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"quiero aprender agentes de WhatsApp","limit":5}'
keywordMás barato

PostgreSQL Full Text Search. No ejecuta modelos.

semanticMás flexible

Busca significado con embeddings OpenAI sobre clases y transcripciones.

hybridMejor ranking

Combina palabras y significado, incluyendo fragmentos y recursos.
