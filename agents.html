BÚSQUEDA BETA

Encuentra qué estudiar según tu intención

Los tres modos comparten la misma entrada y respuesta. El piloto actual usa contexto liviano de las clases de WhatsApp; no indexa transcripciones.

Buscar por palabras clave
curl -X POST "$BASE_URL/search/keyword" \
  -H "X-API-Key: $LEARN_FORCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"quiero aprender agentes de WhatsApp","limit":5}'
keywordMás barato

PostgreSQL Full Text Search. No ejecuta modelos.

semanticMás flexible

Interpreta el significado mediante embeddings.

hybridMejor ranking

Combina ambas listas en una respuesta.

INTERACCIÓN

Actualizar el progreso

El agente solo puede escribir en el progreso de la cuenta que creó la llave.

Marcar como completado
curl -X PUT "$BASE_URL/progress/ID_DE_LA_CLASE" \
  -H "X-API-Key: $LEARN_FORCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"completed": true}'
